# AI Interview Practice Portal

A Flask starter application for resume-based mock interviews.

## Included in this first build
- Student registration, login and logout
- Admin dashboard
- Student profile editing
- Interview analytics and score history
- Category-based learning roadmap
- Configurable 5, 10, 15 or 20-question sessions
- Cross-session question history to reduce repeats
- Resume builder (structured free-text resume editor)
- PDF, DOCX and TXT resume upload and text extraction
- Domain and difficulty selection
- 10-question mixed interview (HR, technical, behavioral, situational and communication)
- Previous-question history for the current student and session
- AI answer evaluation through an OpenAI-compatible API
- Demo fallback when no AI API key is configured
- Interview reports and previous-score comparison
- Browser camera preview and browser speech input/output in the interview UI

## Setup (Windows / VS Code)
1. Extract the ZIP.
2. Open the extracted `ai_interview_practice_portal` folder in VS Code.
3. Open Terminal > New Terminal.
4. Create a virtual environment:
   `py -m venv .venv`
5. Activate it in PowerShell:
   `.venv\Scripts\Activate.ps1`
6. Install packages:
   `pip install -r requirements.txt`
7. Copy `.env.example` to `.env` and edit the settings.
8. Start:
   `python app.py`
9. Open `http://127.0.0.1:5000`.

## Initial administrator

Password: `Admin@123`

Change these credentials in `.env` before using the portal beyond local testing.

## Real AI configuration
Add your provider API key to `AI_API_KEY`. Set `AI_BASE_URL` and `AI_MODEL` to the values supported by your chosen OpenAI-compatible provider. API usage may incur charges. Never share or commit your API key.

Without a key, the app runs in demo mode. Demo questions are randomized from a varied pool, but they are not genuinely generated by an AI model and demo scoring is heuristic.

## Current scope and limitations
- This is a local development starter, not a production deployment.
- Camera is a live preview only in this starter; it does not infer emotions, honesty, personality or confidence.
- Voice input/output uses browser-supported Web Speech APIs and varies by browser.
- The virtual human avatar integration, AI-assisted semantic duplicate detection across all prior sessions, MediaPipe posture/gaze indicators, password reset, email verification, CSRF hardening, rate limiting, and production deployment are planned next phases.
- The interview stores answers and reports in SQLite. Do not upload sensitive personal information unless you are comfortable storing it locally.
